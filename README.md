# DeskTabs releases

Update feed and release artifacts for [DeskTabs](https://github.com/nicopkrauss/DeskTabs),
a macOS menu-bar utility that gives each Mission Control desktop a title and tint.

- **Appcast:** <https://nicopkrauss.github.io/desktabs-releases/appcast.xml>
- **Downloads:** see [Releases](https://github.com/nicopkrauss/desktabs-releases/releases/latest)

DeskTabs updates itself with [Sparkle](https://sparkle-project.org). Installed
copies check this feed daily. This repository exists only to serve that feed and
host the signed, notarized disk images — the application source lives elsewhere.
